# AI מאפס: בלי שום ספרייה

## 💬 ניצוץ: בוט שאפשר לדבר איתו

ניצוץ הוא מודל שפה קטן שלמד לענות בעברית. כל החלקים שלו נכתבו כאן מאפס.

```bash
cd ai-from-scratch
python3 chat.py           # שיחה בטרמינל
```

או בדפדפן: פותחים את `chat.html` דרך שרת קטן (`python3 -m http.server`, ואז http://localhost:8000/chat.html).
בדף רואים גם "איך בחרתי כל מילה": אילו מילים ניצוץ שקל בכל שלב, ובאיזו הסתברות.

**ללמד אותו דברים חדשים:** מוסיפים בלוק לקובץ `dialogues.txt`:

```
ש: מה הקבוצה האהובה עליך?
ש: באיזו קבוצה אתה תומך?
ת: מכבי! מה איתך?
```

ואז מאמנים מחדש: `python3 train_chat.py` (כ-25 דקות).
או, הרבה יותר מהר, ממשיכים מהמודל הקיים: `python3 train_chat.py --resume --steps 1500 --lr 0.005`.

**מה הוא יודע ומה לא:** ניצוץ זוכר בעיקר את מה שלימדו אותו, ומבין גם ניסוחים קרובים.
על שאלה שאין לה שום דבר דומה בקובץ הוא ינחש, ולפעמים ייצא משהו מוזר.
ככה בדיוק נראה מודל שפה כשהוא קטן מאוד ויש לו מעט נתונים. ChatGPT בנוי מאותם רעיונות, רק גדול פי מיליון ומאומן על כמעט כל האינטרנט.

## 🔤 ממציא השמות

מודל שפה (GPT קטנטן) שנכתב **מאפס לגמרי**: בלי PyTorch, בלי TensorFlow, ואפילו בלי NumPy.
יש כאן רק פייתון רגיל, וכל שורה מוסברת.

המודל לומד מרשימה של שמות עבריים וממציא שמות **חדשים** שנשמעים אמיתיים:

```
דורה  ערון  יעודה  אליף  אליאל  תאל
```

## הרצה

צריך רק Python 3, בלי שום התקנה.

```bash
cd ai-from-scratch
python3 test_engine.py          # בודק שהמתמטיקה נכונה
python3 train.py                # מאמן (כחצי דקה)
python3 generate.py             # ממציא שמות חדשים
python3 generate.py --start אל  # שמות שמתחילים ב"אל"
python3 generate.py -t 1.3      # יותר יצירתי ומשוגע
```

כדי ללמד אותו משהו אחר, שים בקובץ טקסט מילה או משפט קצר בכל שורה:

```bash
python3 train.py --data my_words.txt --steps 4000
```

## איך זה בנוי

| קובץ | מה הוא עושה |
|---|---|
| `engine.py` | **המוח המתמטי**: כל מספר זוכר ממה הוא נוצר, וכך אפשר לחשב אוטומטית כמה כל פרמטר אשם בטעות (גזירה אוטומטית, backpropagation). |
| `model.py` | **המודל**: GPT עם Embedding, Attention, MLP ו-RMSNorm, אותה ארכיטקטורה כמו במודלי שפה גדולים, רק זעירה. |
| `train.py` | **הלמידה**: מראים לו שם, הוא מנחש כל פעם את האות הבאה, מודדים את הטעות ומתקנים עם האופטימייזר Adam (גם הוא כתוב מאפס). |
| `generate.py` | **היצירה**: טוען את המודל המאומן ומייצר שמות חדשים אות אחרי אות. |
| `test_engine.py` | **בדיקה**: משווה את הנגזרות של המנוע לחישוב "בכוח", כדי לוודא שהכל נכון. |
| `names.txt` | נתוני האימון: כ-350 שמות עבריים. |
| `model.json` | מודל השמות, מאומן ומוכן לשימוש. |
| `tokenizer.py` | **הבוט**: מפרק משפט למילים, ומבין גם מילים עם אותיות שימוש (ו, ה, ב...). |
| `dialogues.txt` | **הבוט**: השיחות שממנו ניצוץ לומד. |
| `train_chat.py` | **הבוט**: האימון של ניצוץ. |
| `chat.py` | **הבוט**: שיחה בטרמינל. |
| `chat.html` | **הבוט**: שיחה בדפדפן. אותו מודל, כתוב מאפס גם ב-JavaScript. |
| `chat_model.json` | ניצוץ, מאומן ומוכן לשיחה. |

## הרעיון בשלושה משפטים

1. המודל מקבל אותיות, ולכל אות הוא נותן "ציון" לכל אות שיכולה לבוא אחריה.
2. בזמן האימון בודקים כמה הוא נתן לאות הנכונה, וזזים בכיוון שמגדיל את הסיכוי שלה (gradient descent).
3. אחרי אלפי חזרות הוא קולט את החוקים של השפה, למשל ש"ם" באה בסוף מילה ושאחרי "אל" בא הרבה "י".
