# המחברת של יונתן: התקנה על Galaxy Z Fold 7

זו אפליקציית אינטרנט שמתקינים למסך הבית (PWA). צריך אינטרנט רק פעם אחת, בזמן ההתקנה. אחר כך היא עובדת גם בלי אינטרנט, וכל המידע נשמר רק בטלפון.

## 1. העלאה לאתר חינמי (פעם אחת)
**GitHub Pages:**
1. ב-github.com יוצרים מאגר (repository) חדש בשם `yonatan-notebook`.
2. Add file ← Upload files, וגוררים לשם את כל התוכן של התיקייה הזאת (כולל התיקיות `js`, `lib`, `icons`, `geo`).
3. Settings ← Pages ← Branch: `main` ← Save.
4. אחרי כדקה הכתובת תהיה `https://<שם-המשתמש>.github.io/yonatan-notebook/`

(אפשר גם להשתמש ב-Netlify Drop: גוררים את התיקייה לאתר app.netlify.com/drop ומקבלים כתובת.)

## 2. התקנה ב-Fold
1. פותחים את הכתובת ב-**Chrome**.
2. תפריט ⋮ ← **"הוספה למסך הבית"** ← **התקנה**.
3. מעכשיו פותחים את האפליקציה מהאייקון.

## מה יש בפנים
- **🏠 בית:** יעד יומי ב-XP, רמות, רצף ימים 🔥 ומבחנים שמתקרבים. כשמגיעים ליעד אפשר לשלוח להורים בלחיצה אחת מה עשית היום.
- **📚 שיעורי בית:** מעלים את ה-PDF מהמורה, מצלמים את המחברת ומקבלים מסמך מוכן להגשה בוואטסאפ או במייל.
- **🇬🇧 אנגלית:** רשימת Unit 1 · Festivals מוכנה מראש, ואפשר להדביק רשימה משלך ("word - תרגום"). מתרגלים בכרטיסיות, עם הקראה, בחירה בין אנגלית לעברית לשני הכיוונים, האזנה, איות, Present Simple ומבחן מסכם עם ציון. מילים שקשות לך חוזרות יותר.
- **📝 מבחני מתמטיקה ו-📐 גאומטריה:** שאלות מפורקות לשלבים ובונה הוכחות.
- **🐍 פייתון:** 8 יחידות של "מה יודפס?". כל תשובה במאגר נבדקה בהרצה אמיתית של הקוד.
- **⏱️ פוקוס:** טיימר פומודורו שמשאיר את המסך דולק. כל דקה שווה XP.
- **🗓️ יומן:** משימות ומבחנים עם ספירה לאחור.
- **📊 התקדמות:** מפת חום של 12 שבועות, הישגים ושינוי היעד היומי.

## מותאם ל-Fold 7
- **מקופל (מסך חיצוני):** סרגל ניווט למטה, אריחים בשתי עמודות וטקסט קומפקטי.
- **פתוח (מסך פנימי):** סרגל ניווט בצד ותצוגה בשני חלקים. בגאומטריה, למשל, השאלה מוצגת בצד אחד וההוכחה בצד השני.
- **Flex Mode (מקופל לחצי):** בטיימר הפוקוס השעון עובר לחצי העליון והכפתורים לחצי התחתון.
- מצב כהה שחוסך סוללה במסך OLED. אפשר לבחור בהגדרות: לפי הטלפון, כהה או בהיר.

## לחסום טיקטוק
המחברת לא יכולה לחסום אפליקציות אחרות, כי היא רצה בתוך Chrome. בתוך האפליקציה יש מסך "🔒 חסימת טיקטוק" שמסביר איך להשתמש בכלים המובנים של סמסונג: טיימר לאפליקציה, מצבים ושגרות ו-Google Family Link.
