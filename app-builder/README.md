# ✨ בונה האפליקציות

בונים אפליקציות, משחקים ואתרים בשתי דרכים, בלי אינטרנט ובלי מפתחות:

1. **🧩 בלוקים:** גוררים בלוקים בעברית (מסך, אירועים, פעולות, תנאים, לולאות, משתנים) ורואים את האפליקציה מתעדכנת מיד.
2. **🤖 עוזר:** כותבים בעברית מה רוצים ("משחק שתופסים בו חתולים", "אתר למסעדת פיצה של דני"), והעוזר בונה את זה מבלוקים. אחר כך אפשר לבקש שינויים ("רקע ירוק", "יותר מהר", "תוסיף כפתור 'שלום'", "תחליף לכלב") או לשנות בעצמך בבלוקים.

העוזר רץ כולו בדפדפן. הוא מזהה סוגי אפליקציות ובקשות שינוי לפי מילים, כך שהוא מבין סט מוגדר של בקשות ולא כל משפט. "מה אתה יודע?" מציג את הרשימה.

מה העוזר יודע לבנות: משחקים (תפיסה, התחמקות, ריצה וקפיצה, מעופף, יריות, אוצרות ומרדף, לחיצות), חידון (חיות, ישראל, חלל, חשבון), רשימת משימות/קניות, אתר (מסעדה, חנות, צלם, מספרה, קבוצה), שעון עצר/טיימר, קוביה/הגרלה, מחשבון, מונה לייקים, אפליקציית היכרות ומשחק זיכרון.

## ✨ מצב AI
בלוח העוזר יש מתג **✨ AI**. מתארים כל משחק, אפליקציה או אתר, ואז:
- **AI שכותב קוד** כותב קובץ HTML שלם. התשובה מגיעה בהזרמה, ואם היא ארוכה מדי לבקשה אחת, היא ממשיכה אוטומטית. השרת מנסה לפי הסדר: Claude (רק אם יש `ANTHROPIC_API_KEY`), Gemini (המסלול החינמי, עם `GEMINI_API_KEY`), Pollinations (חינמי, בלי חשבון).
- **AI של ציור** מצייר את הדמויות והרקעים במקביל: Gemini, Cloudflare או Pollinations (חינמי). הרקע של כל דמות מוסר בדפדפן, והציורים נשמרים בענן (bucket בשם `game-assets`).
- אפשר לבקש שינויים, וה-AI מקבל את הקוד ואת הציורים הקיימים.

הכל עובר דרך שרת קטן ב-Supabase (`supabase/functions/ai`), שמחזיק את המפתחות. בדפדפן אין אף מפתח סודי. יש מכסה יומית לכל משתמש: `AI_DAILY_BUILDS` (ברירת מחדל 10) ו-`AI_DAILY_IMAGES` (ברירת מחדל 40). אפשר להפעיל את כל זה ב-0 ₪.

התקנה: מריצים את `supabase/ai.sql`, מתקינים את הפונקציה `ai` בלי בדיקת JWT מובנית (הפונקציה בודקת את המשתמש בעצמה), ומוסיפים ב-Edge Functions → Secrets את `GEMINI_API_KEY` (רשות, מומלץ).

## 🎮 מנוע המשחקים
בקטגוריה "🎮 משחק" יש במת משחק עם עיצובים (חלל, ים, שמיים, דשא, לילה, מדבר, ממתקים) ודמויות שאפשר להזיז עם החצים, להקפיץ, להפיל בכוח משיכה, לשכפל, לגרום להן לרדוף זו אחרי זו ולירות. יש גם "כש... נוגע ב...", ניקוד, חיים, טיימר, אפקטים, מסך פתיחה ומסך "נגמר המשחק". בטלפון מופיעים כפתורי שליטה. בראש הקטגוריה יש צירופי בלוקים מוכנים.

## עוד
- תצוגה במחשב 💻 או בטלפון 📱, הורדה כקובץ HTML אחד שעובד לבד, ופתיחה בלשונית חדשה.
- לשונית "קוד" מציגה את הקוד שנוצר. "המר לקוד חופשי" יוצר עותק שאפשר לערוך כקוד.
- הפרויקטים נשמרים בדפדפן (localStorage). כשמתחברים (👤 התחברות), הם נשמרים גם בענן ב-Supabase ומופיעים בכל מכשיר.

## פרטים טכניים
- דף סטטי בלי שלב בנייה. פותחים את `index.html` דרך שרת (למשל GitHub Pages).
- `blocks.js`: הגדרות הבלוקים והמרתם לקוד. `runtime.js`: הספרייה הקטנה שנכנסת לכל אפליקציה. `assistant.js`: העוזר. `app.js`: הממשק.
- [Blockly](https://github.com/google/blockly) 13.4.0 (רישיון Apache 2.0) נמצא בתוך `vendor/blockly`, כך ששום דבר לא נטען מבחוץ.
- האפליקציות רצות בתוך iframe מבודד (sandbox).
- חשבונות ושמירה בענן: `cloud.js`, עם הגדרות החיבור ב-`config.js`. הטבלה וההרשאות נמצאות ב-`supabase/schema.sql`, ומריצים אותו פעם אחת ב-SQL Editor של Supabase. ספריית Supabase נמצאת בתוך `vendor/supabase`.
