# ✨ בונה האפליקציות

אפליקציה שבונה אפליקציות, משחקים ואתרים. מתארים במילים מה רוצים, ו-Claude כותב את הקוד ומציג אותו מיד.

## איך משתמשים
1. פותחים את `index.html` (או את הכתובת ב-GitHub Pages: `/app-builder/`).
2. ב־⚙️ הגדרות מדביקים מפתח Claude API (מ-platform.claude.com). המפתח נשמר רק בדפדפן.
3. כותבים מה לבנות ולוחצים 🚀 בנה. אחר כך אפשר לבקש שינויים ("תוסיף ניקוד", "תעשה את הרקע כחול").
4. אפשר לראות בתצוגת מחשב/טלפון, לערוך את הקוד, להעתיק, לפתוח בלשונית חדשה, או להוריד כקובץ HTML.

בלי מפתח אפשר להתחיל מאחת התבניות המוכנות: אתר תדמית, רשימת משימות, משחק זיכרון, מחשבון.

## פרטים טכניים
- דף סטטי בלי שלב בנייה: `index.html`, `app.js`, `templates.js`.
- משתמש ב-SDK הרשמי `@anthropic-ai/sdk` (נטען מ-jsDelivr) עם המודל `claude-opus-5-5`, בסטרימינג, עם מעבר אוטומטי למודל חלופי אם הבקשה נדחית.
- הקוד שנוצר רץ בתוך iframe מבודד (sandbox), כך שאין לו גישה למפתח השמור.
- הפרויקטים נשמרים ב-localStorage של הדפדפן.
