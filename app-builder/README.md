# ✨ בונה האפליקציות

בונים אפליקציות, משחקים ואתרים בשתי דרכים, בלי אינטרנט ובלי מפתחות:

1. **🧩 בלוקים:** גוררים בלוקים בעברית (מסך, אירועים, פעולות, תנאים, לולאות, משתנים) ורואים את האפליקציה מתעדכנת מיד.
2. **🤖 עוזר:** כותבים בעברית מה רוצים ("משחק שתופסים בו חתולים", "אתר למסעדת פיצה של דני"), והעוזר בונה את זה מבלוקים. אחר כך אפשר לבקש שינויים ("רקע ירוק", "יותר מהר", "תוסיף כפתור 'שלום'", "תחליף לכלב") או לשנות בעצמך בבלוקים.

העוזר רץ כולו בדפדפן. הוא מזהה סוגי אפליקציות ובקשות שינוי לפי מילים, כך שהוא מבין סט מוגדר של בקשות ולא כל משפט. "מה אתה יודע?" מציג את הרשימה.

מה העוזר יודע לבנות: משחק לחיצות, משחק תנועה עם חצים, חידון (חיות, ישראל, חלל, חשבון), רשימת משימות/קניות, אתר (מסעדה, חנות, צלם, מספרה, קבוצה), שעון עצר/טיימר, קוביה/הגרלה, מחשבון, מונה לייקים, אפליקציית היכרות ומשחק זיכרון.

## עוד
- תצוגה במחשב 💻 או בטלפון 📱, הורדה כקובץ HTML אחד שעובד לבד, ופתיחה בלשונית חדשה.
- לשונית "קוד" מציגה את הקוד שנוצר. "המר לקוד חופשי" יוצר עותק שאפשר לערוך כקוד.
- הפרויקטים נשמרים בדפדפן (localStorage).

## פרטים טכניים
- דף סטטי בלי שלב בנייה. פותחים את `index.html` דרך שרת (למשל GitHub Pages).
- `blocks.js`: הגדרות הבלוקים והמרתם לקוד. `runtime.js`: הספרייה הקטנה שנכנסת לכל אפליקציה. `assistant.js`: העוזר. `app.js`: הממשק.
- [Blockly](https://github.com/google/blockly) 13.4.0 (רישיון Apache 2.0) נמצא בתוך `vendor/blockly`, כך ששום דבר לא נטען מבחוץ.
- האפליקציות רצות בתוך iframe מבודד (sandbox).
